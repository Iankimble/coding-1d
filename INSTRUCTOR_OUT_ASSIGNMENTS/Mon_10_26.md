## Rock, Paper, Scissors Function
Using what you've learned through the course andcreate a simple rock paper scissors game function. 
Your game should allow the user to enter one of the following values; r for rock, p for paper, s for scissors and q to quit. Once the user makes a selection, your program will randomly make a selection or rock, paper, or scissors. Following the rock, paper, scissors rules, either the player will,
win, lose, or tie the round. Your function should also keep track of the score for the user and the cpu.
The game loop should run for 3 rounds. Once the user has played for 3 turns, the game should end and the program should print the final scores. If the player enters q, the game loop should end and the function should stop running.

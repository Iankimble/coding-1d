## Vending Machine Function
Using what you've learned about while loops,
create a Vending machine function that will dispense an item depending on an input.

While your functions loop is running, your program should allow the user to enter a number associated with a vending machine item. When the number is entered the vending machine should print out the appropriate item associated with that number (for example if the user enters D3 they should get water). The program should then loop and ask if they would like to enter another value or stop. If the user enters q the loop will end and the function will stop. 

Provided is the vending machine menu items and
the corresponding vending machine number. Use this for your vending machine function

| Vending machine item      | Vending machine number | 
| :---        |    :----:   |
| Nacho Chips      | B3       | 
| BBQ Chips   | G4        |
| Plain Chips   | G7        |
| Water   | D3        |
| Cola Soda   | G5        |

# Dice Rolling Game
Create a dice-rolling game function. Your function should do the following; allow the player to enter a value. If they enter
the letter r for roll the game loop will begin. Else, if they enter q they will quit the game and end the function. If the player rolls a 7 they will win and they're score goes up by 10. they will then have the option to roll again or quit. If the player rolls anything other than 7 they will loss 5 points.
When the player rolls, it needs to be a value between 1 and 7.

To create this program you will need to use the <b>randint()</b> built in function. You can learn more about this using the w3schools article below

[RandInt() Function W3 schools](https://www.w3schools.com/python/ref_random_randint.asp)
